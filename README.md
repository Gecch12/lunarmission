# LUNAR MISSION - ARTEMIS II v0.6.1

A cooperative browser game inspired by the mission architecture and engineering principles of NASA's Artemis II crewed lunar flyby.

## Design changes
- The free-return trajectory is the central game board.
- Five mission phases follow the flight from Earth orbit to splashdown.
- Each phase has five challenge cards; verify three to continue.
- Roles receive complementary private clues and forbidden words.
- Shared action points and persistent spacecraft margins create strategic trade-offs.
- The spacecraft marker advances visibly around Earth, the Moon, and home.

This is a fictional private game and is not affiliated with or endorsed by NASA.
